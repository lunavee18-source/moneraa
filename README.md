## ✅ Step-by-step to add a photo

1. Take your photo (or use your shoot photos)
2. Rename it — e.g. `p1.jpg` for the first product
3. Copy it into the correct folder — e.g. `images/products/p1.jpg`
4. Refresh your browser — it appears instantly!

**If the photo doesn't appear** — check the filename is exactly right (no capital letters, correct folder).

**If no photo is added** — the website shows a beautiful gradient instead, so it always looks good.

---

## 🖼️ Photo tips for luxury look

- Use **portrait orientation** (tall, not wide) for products
- **White or cream background** works best for clothing
- **Natural light** photos look most luxurious
- **JPG format** is fine, keep file size under 1MB each
- You can also use `.png` or `.webp` — just rename the `src` in index.html

## 🚀 Run in VS Code

1. Open the `moneraa` folder in VS Code
2. Install **Live Server** extension
3. Right-click `index.html` → **Open with Live Server**
